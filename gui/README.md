# docver-gui

Word 文档的本地版本管理与逐词对照，原生窗口，不需要 Word、不需要云。

左侧是快照列表（就是一个 git 仓库的历史），中间是红黑对照。工具栏每个按钮都对应
`docver` 命令行的一个动作，命令行能做的这里都能做，反过来也一样。

## 安装

```bash
./install.sh          # 装到 ~/.local/bin/docver-gui + 桌面图标
docver-gui ~/demo-docs/合同.docx
```

`install.sh` 只做三件事：拷二进制、拷图标、拷 `.desktop`。要卸载就删这三样。

## 用法

1. 打开一个目录（或把一个 `.docx` 拖进窗口）。目录不是仓库时，点「在此新建仓库」。
2. 在 Word 里改文件，保存。
3. 回到这里，右边已经是新内容，左边是上一个快照——默认就在回答「我上次存之后改了什么」。
4. 满意了就写一句说明、点「存快照」。
5. 想看任意两版：点版本行的**左半**选为旧版，点**右半**选为新版。**右键**任一版本会把
   它写成一个新文件放在旁边（`合同.5dd700c.docx`），绝不覆盖你正在改的那份。

`并排` / `统一视图` 切换布局，`暗` / `亮` 切换配色，`上一处` / `下一处` 在改动之间跳。
左下角「上下文」控制未改动段落保留几行——0 是只看改动。

## 为什么是原生

同一套引擎有两份实现：Python 版（仓库根目录，46 个测试）和这里的 Rust 版
（`src/engine/prosediff.rs`，18 个测试）。Rust 版是逐行对照移植的，包括三个关键决定：

- **段落对齐用相似度，不用位置。** 插入一段之后，按位置配对会让后面每一段都错位。
  这里用 Needleman–Wunsch，配对得分 `相似度 − 0.35`，跳过代价为 0，所以插入的段落
  不会推动别的段落；相似度太低的直接显示成「删一段、加一段」，不拼成词不达意的混合文本。
- **中文按单字切词，英文按词。** 所以 `壹佰[-贰-]{+伍+}拾万元` 能精确到字。
- **docx 自己解。** 用 `zip` + `quick-xml` 直接读 `word/document.xml`，不依赖 pandoc，
  也不启动外部进程；只有 `.doc`/`.wps` 这种老格式才退回 LibreOffice。

## 编译

```bash
cargo build --release      # 16 核约 37 秒，链接用 mold
```

`.cargo/config.toml` 里写死了 `-fuse-ld=mold`。没装 mold 的机器上把它删掉或改成
`lld` 即可，只是链接慢一点：

```bash
sudo dnf install mold      # Fedora
sudo apt install mold      # Debian/Ubuntu
```

`Cargo.toml` 的 release 配置是为这个程序挑的：`lto = "fat"`、`codegen-units = 1`、
`panic = "abort"`、`strip = "symbols"`。产物 10.9 MB，只动态链接 4 个库
（libz、libgcc_s、libm、libc），其余全静态。

eframe 用的是 `glow`（OpenGL）而不是 `wgpu`：这是个 2D 文字程序，wgpu 的着色器编译
和管线状态没有任何东西可换。

## 字体

正文是 Noto Serif CJK SC，界面是 Noto Sans CJK SC。两个都是**可变字体集合**，直接读
会踩两个坑，代码里都处理了（`src/theme.rs`）：

- `.ttc` 里有 5 个面：JP / KR / SC / TC / HK。**索引 2 才是简体**，选错会得到日文字形
  （骨、直、令 的写法都不同）——一份要签字的合同里这是实打实的错误。
  `fc-scan` 报的 262146 是 fontconfig 的复合编号（面 × 131072 + 具名实例），不是面索引。
- 两个集合的默认字重是最细的那一档（无衬线 100，衬线 200），不显式设 `wght = 400`
  会整个界面发虚。

字体缺失时会退回内置字体，并在左下角提示。

## 没有做的

导出带修订标记的 `.docx`。伪造 Word 的修订 XML 有被 Word 静默「修复」的风险，
而一份坏掉的合同比一页对照视图糟得多。要看修订稿就用 Word 自己的「比较」。
